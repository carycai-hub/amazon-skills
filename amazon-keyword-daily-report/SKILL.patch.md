# 版本记录

## 1.2.0

- 横向日报升级为运营指挥台，强化摘要、排名路径和涨跌状态的视觉层级。
- 变化原因与今日工作安排合并为连续决策区，数据来源降为证据层。
- 保持 HTML/PNG 同源、主图校验、排名与 SIF 口径不变。

## 1.1.0

- 横向日报页面升级为精致数据看板；HTML 和企业微信可用截图保持同一布局。
- 左上角新增按 ASIN 自动核验的产品主图，下载后内嵌；缺图、错配或网络失败显示“主图暂缺”，不阻断日报。
- 主图来源只作为展示字段，独立企业微信步骤发送 PNG，Skill 不包含推送动作。

## 1.0.1

- 用户可见名称由“亚马逊关键词日报”调整为“亚马逊关键词排名日报”。
- 保留内部调用 ID `amazon-keyword-daily-report`，避免破坏既有触发方式和目录引用。

## 1.0.0

- 新建交互式 ASIN、关键词、采样时间输入契约。
- 固化西柚小时自然位/广告位与 SIF 增强分析的来源边界。
- 新增基础版、部分增强、完整增强和安全阻断路由。
- 新增同源 HTML/PNG 渲染脚本与 8 项确定性回归。
- 截图进程加入 12 秒超时，防止 Chrome 残留导致任务卡住。
- SIF 全局口径不匹配时禁止由候选词模块单独升级报告版本。

## 反馈闭环

以后出现以下失败时，先补入 `references/golden-set.md`，再修改脚本并重跑同批测试：误触发、时点错位、站点回落、排名类型混用、截图截断、SIF 版本误判或敏感字段泄漏。
