# 亚马逊关键词排名日报

_v1.2.0_

## 业务背景

把“查询一个 ASIN 的多个关键词在固定时点的自然位和广告位，对比前一日，并结合 SIF 判断变化原因”的重复工作固化为稳定日报。目标是减少手工复制、页码换算、错位对比和报告截图不一致。

输入质量基线为 A：流程已真实运行，输入、输出、数据源、失败边界和验收信号明确。

## 当前工作流（人工版）

1. 人工输入 ASIN、关键词和采样时点。
2. 在西柚逐个查询当日与前一日的小时自然位、广告位。
3. 把总排名换算为 `P页码-总排名`，逐格判断上升、下降、新增和消失。
4. 查询 SIF 最新闭合日流量、BSR、价格和候选流量词。
5. 整理为表格，生成 HTML，再截成图片。

主要痛点是重复查询、时间点错位、自然位与广告位混用、美国当天未闭合时过度解读，以及 HTML 与截图内容不一致。

## 触发场景

- “帮我生成一个 ASIN 的关键词排名日报。”
- “查这几个关键词今天和昨天 08:00、12:00、14:00、17:00 的自然位和广告位，输出 HTML 和截图。”
- “调用关键词日报 Skill，ASIN 是 B0GCZFMWFM。”
- “给这个产品跑一次西柚排名 + SIF 流量分析日报。”

不适用于：只查单个即时排名、分析广告报表、修改竞价或预算、改 Listing、推送企业微信、批量店铺写操作。

## 输入契约

### 必填参数

1. `asin`：10 位 ASIN。
2. `keywords`：1–30 个关键词，保持用户原始顺序。
3. `sampling_times`：1–8 个 `HH:MM` 时点，按目标站点当地时区。

### 可选参数

- `marketplace`：默认 `US`。
- `report_date`：默认取执行时刻对应的站点当地日期；北京时间早间运行时通常对应美国前一自然日。
- `comparison_date`：默认 `report_date - 1 天`。
- `report_edition`：`auto|basic|enhanced`，默认 `auto`。
- `output_dir`：默认当前任务目录下 `output/keyword-daily-report/`。
- `time_tolerance_minutes`：默认 `0`，只取精确时点；非零时必须在报告中标注实际采样时间。
- `product_image`：默认按 ASIN 自动查询西柚详情；图片是可选展示字段，取不到不阻断日报。

### 缕询规则

只询问缺失的必填项，不重复询问已提供内容。缺少参数时使用以下短表单：

```text
请补充本次关键词日报参数：
1. ASIN：
2. 关键词：每行一个或用逗号分隔
3. 采样时间点：按站点当地时间，例如 08:00、12:00、14:00、17:00
可选：站点（默认 US）、报告日期（默认站点当地今天）
```

用户提供自然语言时间时先规范为 `HH:MM`，再用一句话回显参数。ASIN 格式错误、关键词为空、时间非法或重复时，停止查询并指出具体字段。

## Skill 工作流（自动版）

### 第 1 步：确认口径

1. 收集并校验输入。
2. 明确站点时区、报告日、对比日和采样时点。
3. 回显：“站点当地时间｜报告日 vs 对比日｜关键词数｜采样时点”。
4. 默认同一时点严格对比；不得把 12:00 与 14:00 混比。

### 第 2 步：查询基础排名

优先使用当前可用的西柚 MCP 工具 `get_asin_keyword_rank_hourly`，对每个关键词分别查询报告日和对比日。每次调用至少传入：

- `asin`
- `country`
- `date`
- `keyword`
- 清楚说明自然位、广告位、目标时点和同一时点对比的任务描述

提取 `displayPosition=or` 为自然位，`displayPosition=sp` 为广告位。保存工具名、读取时间、请求站点、返回站点和数据日期，不记录 URL 查询参数、认证头或凭证。

若当前无法发现西柚工具，可接受用户提供的西柚小时排名 JSON/CSV 作为人工基础来源；否则输出基础数据缺口并停止，不生成空壳报告。

### 第 3 步：查询 SIF 增强数据

在 `report_edition=auto|enhanced` 时，优先使用已配置的 `sif-v2`：

- `sifv2_asinOpTrafficTrend`：查询截至报告日的最近 14 天，选择不晚于报告日的最新闭合日。
- `sifv2_asinKeywordsSimpleGroupByWeekly`：查询最近闭合周的流量词，排除已跟踪关键词后选 1–2 个高相关候选词。

SIF 用于总流量、自然流量、广告流量、SP、BSR、价格、评论和候选词分析，不与西柚的绝对排名数值混用。若工具返回 `render_footer`，必须在报告末尾原文保留；没有该字段时不得编造验证链接。

### 第 3A 步：自动取得产品主图

使用西柚 `getAsinDetail` 查询本次 ASIN 和站点，核对返回的 `asin`、`marketplace` 与请求完全一致后，优先取 `zoomImageUrl`，其次取 `imageUrl`。在标准化 JSON 中写入 `productImage` 的 ASIN、站点、URL 和来源，并在来源表增加 `asin_detail`（`display_optional`）。不得根据标题相似度推测图片，也不得改用其他 ASIN 的主图。

渲染器只下载 HTTPS `m.media-amazon.com/images/` 图片，限制格式、体积和超时，再内嵌到 HTML；需要网络授权时按运行环境申请。详情工具不可用、身份错配、图片地址不可信或下载失败时，左上角显示“主图暂缺”，保留排名和 SIF 报告，不影响基础版/增强版判定。

### 第 4 步：标准化与计算

1. 页码展示统一为 `P2-13`，表示第 2 页、总排名第 13 名。
2. 排名数字越小越好：`current < previous` 为上升；反之为下降。
3. 昨日无排名、今日有排名记为“新增”；昨日有、今日无记为“消失”；两日都无记为“均未出现”。
4. 自然位与广告位在同一表格单元中上下排列，自然位在上、广告位在下。
5. 流量变化率为 `(当前值 - 前值) / 前值`；前值为 0 或缺失时显示“暂无”，不得补 0。
6. 美国当天尚未结束时，只给当天工作安排，不把未闭合数据当作 ACoS、CVR 或市场需求的完整结论。
7. 自然排名单时点波动 `±5` 位以内视为常规波动；超过 10 位、掉出前 20 或连续多时点走弱才升级提醒。新品、促销、节假日和断货恢复期需单独标注。

排名差值、百分比、版本路由、汇总计数和 HTML 格式转换必须由 `scripts/render-report.mjs` 计算，禁止让模型手算后把结果写死到报告。

### 第 5 步：判断报告版本

按 [报告契约](references/report-contract.md) 执行 `auto|basic|enhanced` 路由。禁止因 SIF 缺失而伪造增强字段，也禁止因某个排名为 `null` 就认定基础查询失败；“查询成功但未出现排名”是有效事实。

### 第 6 步：生成 HTML 和截图

1. 按 [输入数据结构](references/report-input.md) 生成不含凭证的标准化 JSON。
2. 使用同目录脚本生成两个同源产物：

```bash
node scripts/render-report.mjs --input <report-data.json> --output-dir <output-dir>
```

3. 输出文件固定命名为：
   - `keyword-daily-report.html`
   - `keyword-daily-report.png`
4. HTML 必须自包含 CSS 和成功取得的主图，不加载外部脚本、字体或追踪器；截图必须由刚生成的同一套横向 HTML 页面渲染，不另做手机纵向版。
5. 打开或检查 PNG，确认没有截断、重叠、乱码和横向溢出。截图失败时保留 HTML，状态标记为“部分交付”，并说明缺少可用浏览器渲染能力。

### 第 7 步：交付与可选后续

在当前对话提供两个可点击文件链接，并报告：数据日期、SIF 最新闭合日、报告版本、数据质量、缺失项和验证结果。

随后必须附上以下非执行提示，不得自动推送：

```text
是否需要把本报告推送到企业微信？本 Skill 不包含推送动作。
简易步骤：① 在目标群创建群机器人并安全保存 Webhook；② 另建发送步骤读取 HTML 报告生成的 PNG 截图；③ 单次测试成功后再启用定时发送。不要把 Webhook 写入 Skill、报告或代码。

这份日报也可以做成自动化定时任务。请提供执行频率、北京时间、目标站点和失败通知方式；自动化应调用本 Skill 生成报告，推送动作由独立步骤处理。
```

## MCP 数据源建议与路由

- `mcp_selection_mode`: `user_fixed`
- 场景：ASIN × 关键词 × 站点当地小时的自然位和广告位日报。
- 基础主来源：西柚 `get_asin_keyword_rank_hourly`。
- 增强来源：`sif-v2` 经营流量趋势与周流量词。
- 快照证据：本地既有日报项目已在 US 站真实调用过上述工具；每次运行仍需检查工具、Schema、授权和数据新鲜度。
- 用户可改选来源，但替代源必须同时提供同站点、同 ASIN、同关键词、同日期、同小时的自然位与广告位，且语义可比。
- 仅在超时、限流、明确不支持或必需字段缺失时切换到合格来源。
- 站点回落、日期错位、排名类型不一致、凭证泄漏或语义冲突时停止，不得通过换源掩盖。

## 数据来源与指标口径

完整来源表、指标字典和五级字段见 [报告契约](references/report-contract.md)。核心边界：

- 西柚排名是 `basic_required`。
- SIF 口径匹配信息是 `enhancement_global_required`。
- SIF 流量趋势与候选词是两个增强模块。
- 价格、Prime 价、评论、星级和子类名称属于 `display_optional`。
- ASIN 主图属于 `display_optional`；缺图或图片身份不匹配时显示“主图暂缺”，不影响版本路由。
- 截图是必交付格式，但不是数据来源，不参与报告版本判定。

## 核心原则 / 踩坑规避

- 不混用自然位、广告位、ABA 排名、BSR 或其他“排名”。
- 不把报告日未闭合的站点数据描述为完整日结果。
- 不用附近时间替换固定时点，除非用户明确设置容差；替换时必须标注实际时间。
- 不把 `null` 静默写成 0，不平均冲突来源。
- 每条原因判断写明证据等级；仅有当天小时排名时最高为“中等把握”。
- 不执行广告、Listing、企业微信或其他外部写操作。
- 不读取、回显或写入 Webhook、Token、Cookie、App Key、认证头。

### 不要这样做

- 不要用“附近时间”静默替代用户指定的固定时点。
- 不要看到 HTTP 成功就忽略站点、日期或排名类型错位。
- 不要因广告位消失一次就直接建议全局加价。
- 不要把 SIF 的流量分数当成西柚自然排名或广告排名。
- 不要只交付一张截图而不保留可打开的 HTML。

## 输出规范

HTML 至少包含：

1. 左上角 ASIN 产品主图（或“主图暂缺”）、ASIN、站点时区、报告日和对比日。
2. 报告版本、版本原因、数据质量和证据等级。
3. 关键词 × 时点表格，每格自然位/广告位上下排列。
4. 自然位与广告位变化摘要。
5. SIF 经营基线（可用时）。
6. 关键词变化原因、今日工作安排和“暂不建议”。
7. 数据来源、读取时间、缺失项和口径说明。
8. SIF 返回的 `render_footer`（若存在）。

完成信号必须同时满足：HTML 存在、PNG 存在、5 项内容断言通过、产物无敏感字段；否则说明“部分交付”或“阻断”。

## 验证

每次运行至少检查：

- 输入 ASIN、关键词和时间点通过校验。
- 报告日和对比日属于目标站点当地日期。
- 每个关键词具有全部请求时点的查询状态。
- HTML 与 PNG 来自同一标准化数据。
- 主图的 ASIN、站点与报告一致；PNG 直接由同一横向 HTML 渲染。
- 文件不含 `token`、`secret`、`password`、`authorization`、`cookie`、`appKey`、`webhook` 等敏感键。
- 正常打开 HTML，并目视检查 PNG。
