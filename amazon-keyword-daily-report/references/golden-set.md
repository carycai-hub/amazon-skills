# Golden Set

## 案例 1：完整增强日报

- 输入：合法 ASIN、5 个关键词、4 个时点，西柚基础排名与两个 SIF 模块均有效。
- 期望：询问缺失项后生成 HTML + PNG，标签为“增强版报告（完整增强）”。

## 案例 2：只给 ASIN

- 输入：“调用关键词日报，ASIN 是 B0GCZFMWFM。”
- 期望：只追问关键词和采样时间，不重复询问 ASIN。

## 案例 3：SIF 不可用

- 输入：基础排名完整，SIF 超时，`report_edition=auto`。
- 期望：生成基础版 HTML + PNG，说明缺失 SIF，不伪造流量变化。

## 案例 4：显式增强但无 SIF

- 输入：基础排名完整，`report_edition=enhanced`，增强模块均缺失。
- 期望：阻断并列出增强缺口，不生成伪增强报告。

## 案例 5：SIF 口径冲突

- 输入：西柚为 US，SIF 返回其他站点或日期晚于报告日。
- 期望：`auto` 保留基础版；显式 `enhanced` 阻断；不得求平均或静默合并。

## 案例 6：查询成功但广告位为空

- 输入：指定时点成功返回，广告位为 null。
- 期望：显示“—/均未出现/新增/消失”，不把 null 当作查询失败或 0。

## 案例 7：基础时点缺失

- 输入：某关键词的 14:00 没有返回，容差为 0。
- 期望：输出基础数据缺口并阻断完整报告；不得用附近时间替代。

## 案例 8：敏感字段混入输入

- 输入 JSON 含 webhook、token、cookie 或 App Key。
- 期望：任何版本都阻断，只报告敏感字段路径，不回显其值。

## 案例 9：只有流量模块

- 输入：SIF 闭合日流量完整，候选词模块为空。
- 期望：输出“增强版报告（部分增强）”，候选词动作标记 SKIP/MANUAL。

## 案例 10：企业微信与自动化请求

- 输入：报告成功生成。
- 期望：只提示企业微信的三个简易步骤和自动化选项；不读取或发送 Webhook，不创建定时任务，除非用户后续明确要求。

## 案例 11：主图身份一致

- 输入：西柚 `getAsinDetail` 返回与报告相同的 ASIN、站点和可信 Amazon 图片地址。
- 期望：主图出现在横向 HTML 左上角；PNG 由该 HTML 生成，图片内嵌，独立企业微信步骤只使用 PNG。

## 案例 12：主图错配或不可用

- 输入：详情 ASIN/站点错配，或图片地址不可信、下载失败。
- 期望：左上角显示“主图暂缺”；排名日报继续生成，不用其他商品图片补位，不改变基础/增强版判定。
